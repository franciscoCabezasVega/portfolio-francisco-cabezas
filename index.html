How I define “correct” for non-deterministic software

Correctness
Answers checked against a source of truth; LLM judges calibrated by humans.
Safety and security
Prompt injection, data disclosure, prompt leakage, excessive agency (OWASP LLM 2025).
Consistency
Same input run several times against a minimum pass rate.
Tool use
Right tool, arguments and order, checked on traces.
Performance and cost
Latency percentiles and token budgets.

Security is part of quality

Security Testing, from Web to LLMs

OWASP lists as a map, from access control and injection to prompt injection and excessive agency.

OWASP Top 10:2025

Web and API

  • Broken access control: roles, row-level security, cross-user tests
  • Injection and XSS through forms, queries and stored content
  • Authentication: JWT, sessions, expiry, httpOnly cookies
  • Misconfiguration: security headers, CSRF, secrets out of code
  • Supply chain: review of new dependencies

OWASP LLM Top 10 · 2025

LLM applications

  • LLM01 Prompt injection, direct and indirect
  • LLM02 Sensitive data in answers, traces and logs
  • LLM05 Model output rendered or executed unvalidated
  • LLM07 System prompt leakage
  • LLM09 / LLM10 Misinformation and unbounded consumption

OWASP Agentic Top 10 · 2026

Agents and MCP

  • Excessive agency (LLM06): least-privilege tools
  • Goal hijack: external text is data, never instructions
  • Tool misuse: argument validation and authorization per call
  • MCP servers: authentication and tool-scope review
  • Human approval before irreversible actions

Where I have applied it

  • RLS, JWT sessions, AES-256-GCM encrypted keys and a bearer-protected cron in a Next.js and Supabase app, reviewed by a read-only security agent.
  • Pre-ship audits of conversational bots: exposed credentials, data leaks, money safety, prompt injection.
  • Secure test setup in Playwright: credentials from environment variables, reports checked for leaked secrets.
  • Adversarial lessons from identity-verification (KYC) incidents, stored without personal data.
